# ロードマップ

開発の段階を明確に分け、各フェーズで「公開してフィードバックを得る」サイクルを回す。

## Phase 1A — 基盤＋スポット閲覧（現在）

**目標**：庄内エリアの既存データを動的サイトとして公開し、誰でも閲覧できる状態にする。

- [x] Next.js + Tailwind v4 + TypeScript の基盤構築
- [x] shadcn/ui 部品（Tailwind v4 対応版を手書き）
- [x] 山形・庄内モチーフのデザインシステム（OKLCH、ダーク対応）
- [x] 日本語フォント（Noto Sans JP + Zen Kaku Gothic New + Shippori Mincho B1）
- [x] カテゴリ・タグ・市町のマスタ定義
- [x] 旧 places.json → 新 Spot 型変換層
- [x] トップページ（ヒーロー・カテゴリグリッド・注目スポット・ロードマップ）
- [x] スポット一覧（カテゴリ・市町でフィルタ）
- [x] スポット詳細（generateStaticParams で全スポット静的生成）
- [x] 補助制度ページ（庄内5市町のリンク集）
- [x] サービス紹介ページ
- [x] Firebase クライアントスケルトン（env 未設定でも壊れない）
- [ ] Cloudflare Pages へのデプロイ動作確認
- [ ] OGP 画像作成

## Phase 1B — ユーザー投稿・口コミ

**目標**：地域の親が情報をアップデートできるようにする。

- [ ] Firebase プロジェクト作成・`.env.local` 設定
- [ ] `firestore.rules` / `firestore.indexes.json` をリポジトリに追加
- [ ] 既存 JSON データの Firestore シードスクリプト（`scripts/seed-firestore.ts`）
- [ ] Firebase Authentication セットアップ（メール / Google）
- [ ] ログイン／プロフィール画面
- [ ] スポット投稿フォーム（住所→緯度経度の自動取得）
- [ ] 写真アップロード（Firebase Storage、JPEG/WebP 自動圧縮）
- [ ] 口コミ投稿（評価・本文・訪問時の子の月齢）
- [ ] タグ賛同／取り消し投票（`tagVotes` コレクション）
- [ ] モデレーション機能（初回承認制、信頼スコア）
- [ ] 病院カテゴリ・子どもカット対応美容室のデータ充実
- [ ] 投稿に対する Slack 等への運営通知（Cloud Functions for Firebase）

## Phase 1C — 補助制度の構造化

**目標**：制度を月齢・カテゴリで横断検索できるようにする。

- [ ] 庄内5市町の制度を全件調査・データ化
- [ ] `subsidies` コレクションへ投入
- [ ] 月齢・カテゴリでフィルタできる UI
- [ ] 「最終確認日」表示
- [ ] 制度リンク切れ自動チェック（Cloud Scheduler + Cloud Functions）

## Phase 2 — 月齢パーソナライズ

**目標**：子どもの誕生日から、いま必要な情報をプッシュ。

- [ ] 子どもプロフィール登録（複数人対応）
- [ ] 月齢から逆算した「今おすすめ」モジュール
- [ ] 健診・予防接種スケジュール
- [ ] 月齢別関連スポット・補助制度のレコメンド
- [ ] メール通知（Firebase Extensions の Trigger Email、または Resend）
- [ ] LINE ログイン対応（Firebase Custom Auth + LINE OAuth）
- [ ] LINE 公式アカウント連携と通知配信

## Phase 3 — ルート × おむつ替え

**目標**：移動中の不安まで取り除く。

- [ ] 地図表示（MapLibre GL + 国土地理院タイル）
- [ ] 出発地・目的地を入れると道中の赤ちゃんの駅を表示
- [ ] お気に入り／行きたいリスト
- [ ] 県全域（村山・最上・置賜）への対応エリア拡大
- [ ] イベントカレンダー

## Phase 4 — コミュニティ

- [ ] スポットへの質問機能（Q&A）
- [ ] 地域別の親コミュニティ掲示板
- [ ] 信頼スコア上位ユーザーへの「地域エディター」ロール
- [ ] 山形県・地域子育て支援団体とのデータ連携

- 補助制度ページ → 公式サイトへの遷移率
